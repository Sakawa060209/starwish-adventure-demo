# 星愿物语：少女冒险团 — Demo 0.1

一款零构建、可离线运行的 2D 横版像素挂机刷宝浏览器游戏。四名少女会在同一条地面线上自动行进、索敌与施放技能；玩家通过装备、阵型、战术和技能升级突破 10 个关卡。

## 已实现

- 4 名固定职业角色与独立的程序化像素动作：剑士、枪兵、弓手、法师。
- 固定 20Hz 战斗逻辑、横版滚动、近远程射程、箭矢和魔法弹道。
- 10 关、3 种普通怪物、精英史莱姆王和完整花冠鹿灵 BOSS 阶段。
- 3 个装备位、5 档品质、12 条合法词缀、4 件职业传说武器。
- 装备穿戴/对比、锁定/分解、品质保底、背包容量与自动分解。
- 阵型调序、均衡/突击/守护战术、共享等级与四个技能各 3 级升级。
- 自动推进、选关回刷、连续失败回退、BOSS 碎片和指定传说兑换。
- 8 小时上限的离线收益、本地自动存档、导出与导入。
- PC 与窄屏响应式界面。

## 运行

直接打开 `index.html` 即可。建议通过静态服务器运行，例如：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 测试

```powershell
node --test tests/logic.test.js
```

浏览器冒烟测试需要 Playwright：

```powershell
node tests/browser-smoke.cjs
```

存档使用 `localStorage`，键名为 `starwish_demo_save_v1`。Demo 版本为 `0.1.0`，存档结构版本为 `1`。
