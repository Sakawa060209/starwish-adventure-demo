# 星愿物语：少女冒险团 — Art Update 0.3

一款零构建、可离线运行的 2D 横版像素挂机刷宝浏览器游戏。四名少女会在同一条地面线上自动行进、索敌与施放技能；玩家通过装备、阵型、战术和技能升级突破 10 个关卡。

## 已实现

- 4 名固定职业角色与明显不同的 64×80 级程序化像素轮廓、武器和战斗动作。
- 8 帧离散跑步姿态、非均匀攻击关键帧，以及马尾、披风和裙摆的延迟运动。
- 四套独立像素头像、32×32 装备图标与减少圆角/渐变的日式像素 RPG 界面。
- 分组式三至四级材质明暗、暴击停顿、轻量震屏与连续伤害数字合并。
- 史莱姆形变、蘑菇抬盾、蒲公英浮动，以及重新设计轮廓和鹿角的花冠鹿灵。
- 固定 20Hz 战斗逻辑、横版滚动、近远程射程、分层弹道与增强命中特效。
- 10 关、3 种普通怪物、精英史莱姆王和 100—60%、60—30%、30—0% 三阶段花冠鹿灵。
- 破甲＋星痕的「协同爆发」与守护格挡＋枪击的「守望突击」两条队伍联动。
- 3 个装备位、5 档品质、12 条合法词缀、4 件职业传说武器。
- 装备伤害/生存/特殊效果对比、掉落来源、图鉴、锁定/分解、词条保护和等级阈值。
- 阵型调序、三种战术、刷图/BOSS 双预设、共享等级与四个技能各 3 级升级。
- 主线、装备、材料、BOSS 四种挂机方案；重复关卡支持快速巡逻与目标部位筛选。
- 第 3/5/7 关有效装备节点、BOSS 纪录、伤害/承伤/技能/状态覆盖战报与失败诊断。
- 8 小时上限的离线收益、本地自动存档、导出与导入。
- PC 与窄屏响应式界面。

## 运行

直接打开 `index.html` 即可。建议通过静态服务器运行，例如：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 测试

```powershell
node --test tests/logic.test.js
```

浏览器冒烟测试需要 Playwright：

```powershell
node tests/browser-smoke.cjs
```

完整十关自然流程回归：

```powershell
node tests/full-run.cjs
```

存档使用 `localStorage`，键名仍为 `starwish_demo_save_v1`（保障旧存档可读取）。Demo 版本为 `0.3.0`，存档结构版本仍为 `2`。
