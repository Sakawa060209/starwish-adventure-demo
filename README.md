# 星愿物语：少女冒险团 — Battle Polish 0.8

一款零构建、可离线运行的 2D 横版像素挂机刷宝浏览器游戏。四名少女会在同一条地面线上自动行进、索敌与施放技能；玩家通过装备、阵型、战术和技能升级突破 10 个关卡。

- 在线试玩：<https://starwish-adventure-demo.sakawa060209.chatgpt.site>
- GitHub Pages：<https://sakawa060209.github.io/starwish-adventure-demo/>
- 源代码：<https://github.com/Sakawa060209/starwish-adventure-demo>

## 已实现

- 4 名固定职业角色按角色设计稿重绘：银发星纹剑士、紫发星象法师、薄荷绿藤弓手与粉发蔷薇枪姬。
- 每名角色都有独立的长发层次、披风或裙摆、职业武器轮廓和战斗动作；枪姬技能增加蔷薇花瓣轨迹。
- 角色小人采用更精细的 HD-2D 冒险者方向：深色外轮廓、分层材质明暗、细像素发丝与服装纹样、暖色轮廓光和眨眼待机细节。
- 四张角色设计图已经作为正式游戏素材接入：每人使用待机、两帧行走、攻击、技能和受击六种透明像素帧，并统一保持朝右三分之四侧身视角。
- 战斗 HUD、开场队伍预览和编队界面均改用从设计图提取的角色头像；原始设计表保存在 `assets/design/`，可通过提取脚本无损重建游戏帧。
- 行走动作改为接触、下压、过渡、腾空四段节奏；待机加入呼吸与重心起伏，不再整张贴图机械弹跳。
- 攻击与技能使用预备、发力、命中停顿、收势四段动作曲线，并按职业分别设置突进距离与节奏。
- 新增星轨、树叶、花瓣、剑光、脚步尘与低透明残影等二级动态；脚底阴影会随腾空和受击同步形变。
- 四人基础站位间距扩大，近战突进和远程施法的轮廓更容易辨认，降低战斗时的角色遮挡。
- 四套独立像素头像、32×32 装备图标与减少圆角/渐变的日式像素 RPG 界面。
- 分组式三至四级材质明暗、暴击停顿、轻量震屏与连续伤害数字合并。
- 史莱姆形变、蘑菇抬盾、蒲公英浮动，以及重新设计轮廓和鹿角的花冠鹿灵。
- 固定 20Hz 战斗逻辑、横版滚动、近远程射程、分层弹道与增强命中特效。
- 四职业会按 40/70/200/270 像素战术距离动态跟进；远程在威胁贴近时后撤，避免站桩掉队。
- 守护战术加入露米真实拦截，蒲公英精灵会点名后排；战报记录每人有效攻击、拦截与后排受击。
- 10 关、3 种普通怪物、精英史莱姆王和 100—60%、60—30%、30—0% 三阶段花冠鹿灵。
- 第 6 关起蘑菇会保护邻近史莱姆，第 8 关加入星盾；BOSS 召唤存活时会持续为本体治疗，花藤蓄力与普通攻击严格互斥。
- 破甲＋星痕的「协同爆发」与守护格挡＋枪击的「守望突击」两条队伍联动。
- 3 个装备位、5 档品质、12 条合法词缀、4 件职业传说武器。
- 装备伤害/生存/特殊效果对比、掉落来源、图鉴、锁定/分解、词条保护和等级阈值。
- 背包新增四人已穿戴总览、角色/部位筛选与职业推荐；战斗中换装统一在下一波刷新属性并保持生命比例。
- 阵型调序、三种战术、刷图/BOSS 双预设、共享等级与四个技能各 3 级升级。
- 主线、装备、BOSS 三种挂机方案；重复关卡支持快速巡逻与目标部位筛选。
- 第 3/5/7 关有效装备节点、BOSS 纪录、伤害/承伤/技能/状态覆盖战报与失败诊断。
- 稳定关卡以最近 10 场至少 9 胜且无超时判定；离线收益采用近期成功均时和胜率，BOSS 计划可获得花冠碎片。
- 首通传说选择会在弹窗前保存，刷新后自动恢复且只能领取一次；里程碑和兑换奖励不再改变普通掉落保底。
- 8 小时上限的离线收益、本地自动存档、导出与导入。
- 后续版本以 Windows 桌面端为主要验收目标；网页版本仍可运行，但不再把手机端操作作为更新前提。

## 运行

直接打开 `index.html` 即可。建议通过静态服务器运行，例如：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

桌面版开发运行：

```powershell
pnpm install
pnpm desktop
```

生成 Windows x64 单文件 EXE：

```powershell
pnpm build:win
```

构建产物位于 `release/Starwish-Adventure-0.8.0-Windows-x64.exe`。桌面版存档保存在 Electron 的应用数据目录，与浏览器站点存档相互独立；可通过游戏内导出/导入功能迁移。

## 测试

```powershell
node --test tests/logic.test.js
```

浏览器冒烟测试需要 Playwright：

```powershell
node tests/browser-smoke.cjs
```

完整十关自然流程回归：

```powershell
node tests/full-run.cjs
```

存档使用 `localStorage`，键名仍为 `starwish_demo_save_v1`（保障旧存档可读取）。Demo 版本为 `0.8.0`，存档结构版本为 `3`。
